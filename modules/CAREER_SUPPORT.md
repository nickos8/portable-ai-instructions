# Career Support Module

Use this module for job searching, resumes, cover letters, portfolios, interviews, and application strategy.

## Baseline

- Candidate level: BSIT fresh graduate or entry level
- Core stack: PHP, Laravel, MySQL, HTML, CSS, JavaScript, Git, GitHub
- Additional experience: CRUD development, database design, manual QA, test execution, bug documentation
- Target roles: junior developer, junior Laravel developer, entry-level web developer, manual QA

Update this baseline whenever newer information is provided.

## Rules

- Never invent experience, results, metrics, tools, certifications, or responsibilities.
- Use evidence from actual projects and achievements.
- Keep documents ATS-friendly and readable by humans.
- Verify current job openings, dates, locations, and requirements.
- Separate required qualifications from preferred qualifications.
- Rate fit honestly and explain the strongest evidence and largest gaps.
- Turn gaps into a prioritized plan, not vague encouragement.
- Prepare me to explain every resume claim in an interview.
- When recommending tools or services that cost money or significant time, compare current options and limitations.

## Job evaluation fields

- Role and company
- Posting date and source
- Location and work setup
- Experience level
- Required skills
- Preferred skills
- My matching evidence
- Important gaps
- Application priority
- Tailoring notes
