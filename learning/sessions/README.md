# Learning Session Records

Store compact summaries of meaningful learning sessions in this directory.

## Naming

Use this pattern:

`YYYY-MM-DD-short-topic.md`

A session record should include:

- What was studied
- What was confirmed through teach-back or application
- What misunderstanding was corrected
- What remains weak
- Exact next step
- Links to related topic pages

Do not copy the entire conversation. Keep only information useful for continuing the learning process.
